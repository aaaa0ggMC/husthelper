# 补充：实验任务书 / 实验报告 / 课程设计类文档的判断准则与语义理解

## 1. 核心心智模型：理解文档角色与写作者职责

你处理的原文档通常属于以下两类之一：
- **下发给学生的实验报告样例 / 规范参考样本**：包含封面格式、各章节排版要求、示范性的占位符、以及教师给写作者的写作建议。
- **实验任务书 / 指导书**：包含实验目的、任务描述、具体设计题目、客观要求与规则，以及供学生填写作答的预留区域。

你的核心任务是理解写作者的职责，将其提炼为：
1. **纯净的排版底板（`template.docx`）**：供渲染引擎作为模板底板，只保留框架结构与客观题目内容，**绝不残留任何面向写作者的指引、排版提示或占位文字**；
2. **写作者填字稿（`skeleton.md`）**：供实际编辑填写的 Markdown 入口。

---

## 2. 深度理解语义意图：精准决策 `edits` 删除与保留

**极重要原则：不要依靠僵化的字面匹配，而是根据段落内容的“语义受众与功能意图”进行严谨判断！**

系统**完全信任并仅执行**你在 `edits` 中声明的操作（不会有任何硬编码正则替你补充或干预）。因此，你必须细致通读锚点表，做出完整、准确的删除与保留决策。

### A. 什么是必须保留的内容（绝对不能删除！构成模板底板与客观题目）：
- **封面骨架**：封面中的字段名称（专业班级、学号、姓名、指导教师、报告日期等）及填空槽位。
- **目录结构**：目录标题及各章节目录条目（若原文档包含）。
- **正文各级章节标题**：章标题、节标题、附录标题（如 `一、实验目的与要求`、`2.1 系统需求分析`、`任务1 数据压缩`、`参考文献`、`附录` 等）。这些标题的锚点类型标记为 `kind: "insert"`。
- **客观题目与实验任务说明（至关重要）**：
  - 任务书中老师布置的**实验题目描述、数据结构定义、算法任务说明、接口函数签名、客观实现要求、评分比例标准**等；
  - 这是实验或课设的核心题面本身，提交的最终报告必须完整保留题面，**绝对不能当作引导语删除**！

### B. 什么是面向写作者的指引与占位符（必须在 `edits` 中以 `{"op": "delete", "ref": "...", "as": "paragraph"}` 整段彻底删除！）：
原文档中写在章节下方，**其语义目的是在指导写作者“如何撰写报告、格式排版要求是什么、或者仅仅作为示范占位”**的内容，绝不属于最终报告正文，留在模板底板中会变成垃圾残留：
1. **排版格式指引与规范说明**：
   - 指导字体、字号、行距、页边距、对齐方式的文字（例如：“单倍行距，5号宋体字”、“段落前后0行，首行缩进2汉字”、“章标题：黑体小2加粗居中”、“请将所有红色文字和批注删除”等）；
2. **纯示范占位符与省略记号**：
   - 用来示意“此处有大段文字/代码”的符号（例如：连续的 `××××××`、`......(省略号代表后续题目...)`、`[2]......`、空方框 `□` 等）；
3. **写作启发与内容建议**：
   - 启发写作者如何构思或提醒可以写哪些内容的提示语（例如：“这部分主要描述系统中模块实现的流程，可采用文字配合流程图...”、“这部分就自由发挥了，写具体的项目设计与实现中的经验”、“可以写通过本次实验学到了什么知识，有哪些提高，又有哪些不足”等）；
4. **示范性示例与图注**：
   - 教师为了向学生示范格式而放置的示范流程图图片及其示范图注（如“图1-1 程序设计题1的流程图”）；
   - 在“参考文献”章节下的示范性书籍/论文条目（例如示例文献教材条目）。示范参考文献必须在 `edits` 中删除，避免学生填写真实参考文献时与模板底板重复。

---

## 3. 封面垂直对齐与已填字段（极重要）

- 封面通常有一列垂直排布的下划线/填空字段（例如：专业班级、学号、姓名、指导教师、报告日期）。
- **即使原文档中某个字段已经有了默认值（如「专业班级：图灵2501班级」或「指导教师：李老师」已有文字），也必须将其作为槽位写入 `skeleton.md` 并标记 `padding=cover`**（例如 `[图灵2501班级](ref:hrseg0009 | padding=cover)`）！
- **原因**：`padding=cover` 是根据同组所有文本的宽度动态计算对齐基准的。如果遗漏已有文字的字段，会导致下划线长短不齐、上下错位。
- **原则**：凡属于该列垂直对齐区域的所有槽位字段，一律写入 `skeleton.md`，全部统一加上 `padding=cover`。原文档已有的默认文字原样作为初值。

---

## 4. `skeleton.md` 填字稿生成要求

- **与模板互补**：未在 `skeleton.md` 中提及的模板内容会自动保留；
- **只写需填部分**：对封面槽位提供填空；对各正文章节插入点（`# 标题 {ref:...}`），在其下方提供引导学生作答的简明提示占位；
- **参考文献示范**：在 `# 参考文献 {ref:...}` 章节下方，建议为学生提供 1~2 条规范的参考文献格式示范，使用纯文本代码块包裹（如 ```` ```\n[1] 作者. 论文/著作题目. 出版社, 年份.\n``` ````），既直观便于学生修改，又避免 Markdown 链接解析冲突。
