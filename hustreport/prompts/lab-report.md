# 补充：实验 / 课程报告类文档的判断准则

在前面的通用规则之外，对这类文档请**逐段判断**哪些内容该删、哪些该留（不要一刀切）：

- **应删**：面向写报告者的指令、格式 / 排版要求、填写提示、纯占位符。
  例如：「实验任务 1、2 的源程序（单倍行距，5号宋体字）」「请在此填写」「示例：」「粘贴源程序」「此处删除」。
- **应留**：报告自身的标题与章节、实验目的与要求及其列出的条目、实验内容与任务描述、封面字段、需要保留的结构骨架。
  例如：「一、实验目的与要求」「⑴ 熟练掌握程序开发平台……」「二、实验内容」「任务1 数据存放的压缩与解压编程」。
- 拿不准就**保留**。

另外：

- **封面一列对齐与已填字段（极重要）**：
  - 封面通常有一列垂直排布的下划线/填空字段（例如：院系、专业班级、学号、姓名、指导教师）。
  - **即使原文档中某个字段已经有了默认值（如「院系：计算机科学与技术」已有文字、看起来不需要填写），也必须将其作为槽位放入 `skeleton.md` 并标记 `padding=cover`**（例如 `[计算机科学与技术](ref:hrseg0017 | padding=cover)`）！
  - **原因**：`padding=cover` 是根据组内最长文本动态计算宽度的。如果漏掉已预填的院系长文本，剩下的班级、学号、姓名等就只会按自身较短的宽度互相对齐，导致整个封面的下划线长短不一、与上方的院系严重错位！
  - **原则**：凡属于该列垂直对齐区域的所有字段（无论原文档中是空格槽还是已有文字），一律收入 `skeleton.md`，全部统一加上 `padding=cover`。原文档已有文字的原样作为默认内容，方便保留或按需修改。
- 如果某个槽原本是引导行、格式与正文不一致，填充时用 `use:body` 把它拉回正文样式。
