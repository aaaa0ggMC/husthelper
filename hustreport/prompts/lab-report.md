# 补充：实验 / 课程报告类文档的判断准则

在前面的通用规则之外，对这类文档请**逐段判断**哪些内容该删、哪些该留（不要一刀切）：

- **应删**：面向写报告者的指令、格式 / 排版要求、填写提示、纯占位符。
  例如：「实验任务 1、2 的源程序（单倍行距，5号宋体字）」「请在此填写」「示例：」「粘贴源程序」「此处删除」。
- **应留**：报告自身的标题与章节、实验目的与要求及其列出的条目、实验内容与任务描述、封面字段、需要保留的结构骨架。
  例如：「一、实验目的与要求」「⑴ 熟练掌握程序开发平台……」「二、实验内容」「任务1 数据存放的压缩与解压编程」。
- 拿不准就**保留**。

另外：

- 封面这类「一列字段」的槽，记得统一给同一个 `padding` 组名（例如 `padding=cover`），
  这样同组内容会补齐到等宽，下划线/对齐才好看。
- 如果某个槽原本是引导行、格式与正文不一致，填充时用 `use:body` 把它拉回正文样式。
